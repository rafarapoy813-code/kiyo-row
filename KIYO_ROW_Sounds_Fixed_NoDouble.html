🔌 Sambungkan API AI Kiyo

BACKEND

Masukkan URL endpoint backend untuk chat AI. Contoh lokal: http://localhost:3001/api/chat atau /api/chat jika backend satu domain. Backend menerima JSON berisi message, lang, context, product, assistant dan mengembalikan JSON seperti {"reply":"Hai! Aku Kiyo."}.

Endpoint default: /api/chat

Penting: jangan masukkan API key OpenAI/Gemini langsung ke HTML atau browser. Simpan API key di backend server (misalnya file .env). HTML ini adalah frontend yang menghubungi backend.

Sumber: Profil Indonesia EF EPI 2025 · Laporan dan metodologi EF EPI · British Council: English proficiency in Indonesia (PDF).

🧩 Kenapa ini terjadi?

  • Kurang latihan bicara. Speaking (447) dan listening (454) lebih rendah dibanding reading (491).
  • Kesenjangan antar kota. Jakarta dan Bandung jauh di atas rata-rata nasional.
  • Kurang kesadaran dan akses. Fokus kurikulum terbatas dan kemampuan pengajar yang belum merata sering disebut sebagai faktor penyebab.
  • Belajar terasa membosankan. Banyak orang berhenti di tengah jalan karena tidak ada motivasi.

🌱 Cara Kiyo Row membantu

  • Survei personal: target waktu dan tujuan belajarmu (traveling, game, film, dll.) menentukan quest.
  • Gamifikasi: XP, streak, misi harian, dan lencana supaya konsisten.
  • Maskot Kiyo: teman belajar yang ramah dan ikut bereaksi.
  • Latihan suara: mencoba speaking dan listening secara privat; fitur pengenalan suara bergantung pada dukungan browser.
  • Bahasa Indonesia sederhana: penjelasan ramah pemula.
